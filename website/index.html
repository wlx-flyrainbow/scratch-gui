Windows

Windows 安装版 Windows 便携版

安装版适合长期使用；便携版无需安装，解压即可运行。

安装并打开应用后，请使用账号登录。未订阅用户可在应用内前往「订阅解锁」，开通后可使用云保存、作品分享与社区等完整能力。

订单创建、扫码付款、付款凭证提交都在客户端订阅中心完成；通过人工确认后，回到客户端点击「刷新授权」即可。

系统要求

  • macOS 12 或更高版本；Apple 芯片与 Intel 芯片分别下载对应安装包
  • Windows 10 或更高版本（64 位）
  • Windows 安装版需管理员权限完成安装；便携版无需安装，解压即可运行
