# 新祥编程首批家庭邀请与开通指引

用途：发给首批 20 个家庭，帮助家长理解产品、下载安装、注册开通，并开始第一个作品。

发送原则：

- 先发简短邀请，不要一次塞太多说明。
- 对方有兴趣后，再发下载和开通步骤。
- 付款前讲清楚：首发阶段人工确认到账，不是自动支付。
- 不承诺云保存、社区、自动开通或一对一长期课。

## 1. 首次邀请短消息

你好，我最近在做一个少儿创意编程启蒙产品，叫「新祥编程」。

它适合 6-10 岁孩子在电脑上用积木编程做故事、动画和小游戏。我们现在找首批家庭做真实体验和付费验证，不是一上来报几千元课程，而是先让孩子低成本试试能不能喜欢创作。

首发有两个选择：

- 家庭年卡：199 元/年，开通完整编程编辑器。
- 7 天项目陪跑包：699 元/期，适合希望孩子这一周真正做出 3 个入门作品的家庭。

如果你愿意试一下，我发你下载和开通步骤。

## 2. 对方有兴趣后的下载说明

下载官网：

> 请打开新祥编程官网，按电脑系统选择安装包。

选择方式：

- Mac M1 / M2 / M3 / M4：选择 macOS Apple 芯片版。
- 老款 Intel Mac：选择 macOS Intel 芯片版。
- Windows：优先选择 Windows 安装版；如果只是先体验，可选择便携版。

安装后打开新祥编程，先注册账号。注册后还不能直接进入完整编辑器，需要在客户端里点「订阅解锁」完成开通。

## 3. 开通步骤

请按这 6 步操作：

1. 下载并安装新祥编程客户端。
2. 打开新祥编程，注册或登录账号。
3. 点击「订阅解锁」。
4. 选择家庭年卡或 7 天项目陪跑包。
5. 扫码付款，并在付款备注里填写页面显示的订单备注。
6. 回到客户端提交付款凭证，运营确认到账后点击「刷新授权」。

首发阶段是人工确认到账，一般会尽快处理。付款截图只是辅助，最终以真实到账记录为准。

## 4. 年卡说明

家庭年卡适合：

- 想先低成本试试少儿编程启蒙。
- 家长愿意陪孩子打开电脑做一点创作。
- 先看孩子是否愿意继续做故事、动画和小游戏。

开通后获得：

- 完整编程编辑器。
- 客户端账号授权。
- 3 个入门作品建议路径。

当前不包含：

- 云保存。
- 作品社区。
- 自动分享。
- 长期老师一对一教学。

## 5. 7 天项目陪跑包说明

7 天项目陪跑包适合：

- 家长希望孩子这一周真正做出作品。
- 孩子第一次接触积木编程，需要有人提醒路径和处理卡点。
- 家庭想先验证孩子能不能坐下来创作，而不是直接报长期课。

陪跑目标：

- 完成“会说话的小角色”。
- 完成“生日祝福动画”。
- 完成“接水果小游戏”。

交付边界：

- 群内轻陪跑和卡点答疑。
- 不做长期一对一课。
- 不承诺竞赛、考级或系统课程效果。

## 6. 第一个作品开始话术

开通后可以先让孩子做“会说话的小角色”。

目标很简单：不是做复杂项目，而是让孩子第一次看到“我拖了积木，角色真的动了、说话了”。只要孩子愿意继续点、继续试，就是第一阶段成功。

完成后可以把截图或一句反馈发我，比如：

- 孩子是否愿意继续玩？
- 哪一步卡住了？
- 做出了哪个小作品？

## 7. 常见问题回复

### 为什么要注册？

新祥编程通过账号判断是否已经开通。注册只是创建账号，开通后才可以进入完整编辑器。

### 为什么扫码后没有立刻开通？

首发阶段采用固定二维码收款和人工确认到账。你提交付款凭证后，我们会核对真实收款记录，确认后刷新授权即可进入。

### 孩子太小能用吗？

6-8 岁建议家长陪同。新祥编程第一阶段不是让孩子学复杂代码，而是让孩子用积木做出故事、动画和小游戏。

### 是 Scratch 官方吗？

不是。新祥编程基于 Scratch GUI 开源项目做产品化改造，并遵守 AGPLv3 许可。新祥编程是独立产品。
