# 知萌商标与品牌管理计划

## 1. 结论

知萌需要做商标与品牌管理。

原因：

- 知萌已经用于官网、客户端、安装包、支付、运营后台和商业化文案。
- 产品目标是对外售卖，品牌名会承载获客、支付信任和用户口碑。
- 如果真实售卖后再发现商标冲突或被抢注，改名成本会显著高于现在。

## 2. 注册阶段

### 当前阶段：发布前

- 完成“知萌”文字商标近似检索。
- 检索重点为第 9 类、第 41 类、第 42 类。
- 形成申请类别决策。
- 首批真实售卖前提交文字商标申请。

### 首发后

- 观察官网、客户端、客服、支付、社群中的品牌使用一致性。
- 保存实际使用证据：官网截图、安装包、订单记录、付款凭证、宣传文案、用户反馈。
- Logo 和视觉资产稳定后，补充图形商标或组合商标。

### 有稳定营收后

- 根据业务扩展补充第 35 类和第 16 类。
- 建立商标续展、变更、授权和侵权监控台账。

## 3. 推荐类别

| 类别 | 保护方向 | 优先级 |
| --- | --- | --- |
| 第 9 类 | 桌面客户端、可下载软件、计算机程序 | P0 |
| 第 41 类 | 少儿编程启蒙、教育、培训、在线教育 | P0 |
| 第 42 类 | 软件服务、云保存、AI 辅导、平台服务 | P0 |
| 第 35 类 | 线上推广、渠道销售、商业运营 | P1 |
| 第 16 类 | 纸质资料、练习册、课程包 | P2 |

首批建议只做 P0 类别，避免还未验证付费前过度铺开成本。

详细检索词、首批类别、商品/服务项目方向、预算和申请材料见：[`docs/zhimeng-trademark-search-prep.md`](./zhimeng-trademark-search-prep.md)。

公开网页初筛记录见：[`docs/zhimeng-trademark-search-record-2026-05-24.md`](./zhimeng-trademark-search-record-2026-05-24.md)。公共服务平台商标数据实查记录见：[`docs/zhimeng-trademark-official-search-2026-05-25.md`](./zhimeng-trademark-official-search-2026-05-25.md)。

重要更新：2026-05-25 实查显示，“知萌”在第 9/41/42 类均存在相同或高度相关商标，且覆盖 0901 软件、4101 教育培训、4220 软件设计/维护等核心项目。不再建议直接提交“知萌”文字商标第 9/41/42 类申请；应先进入品牌改名评估。

当前执行建议：

- 先检索“知萌”“知萌编程”“ZHIMENG”“zhimeng”。
- 扩展检索“智萌”“芝萌”“萌知”“知萌少儿编程”“知萌创意编程”“知萌启蒙”。
- 首批优先申请文字商标“知萌”的第 9/41/42 类。
- 正式提交前用国家知识产权局商标局当前《类似商品和服务区分表》核准每个商品/服务项目名称。
- 如第 9/41/42 类出现同业高风险近似商标，先做品牌命名风险决策，再继续大规模投放。

调整后执行建议：

- 暂停“知萌”第 9/41/42 类直接提交。
- 进入新品牌候选命名和检索流程。
- 在正式售卖前确认新主品牌，并优先提交第 9/41/42 类文字商标。

## 4. 品牌使用规则

- 主品牌统一写作：知萌。
- 定位语统一写作：少儿创意编程启蒙。
- 产品描述统一围绕：用积木编程做故事、动画和小游戏。
- 不把 Scratch 作为产品名或售卖品牌。
- Scratch 只用于 AGPL 合规、源码披露和必要技术说明。
- 不宣传未上线能力为已交付权益，包括云保存、作品分享、社区、背包和自动支付到账确认。
