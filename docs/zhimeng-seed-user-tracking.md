# 知萌种子用户跟进表

目标：首批 20 个种子用户，验证真实下载、注册、付款、开通和首次创作。

## 1. 首发指标

| 指标 | 目标 |
| --- | --- |
| 官网访问到下载点击率 | >= 25% |
| 下载到注册率 | >= 40% |
| 注册到创建订单率 | >= 20% |
| 创建订单到付款凭证提交率 | >= 50% |
| 首批 20 个种子用户中真实付费 | >= 5 个 |
| 付款后 24 小时内人工确认率 | 100% |

## 4. 每日复盘

每天复盘以下问题：

- 今天触达了多少个家长？
- 有多少人打开官网？
- 有多少人下载客户端？
- 下载失败的原因是什么？
- 注册失败的原因是什么？
- 创建订单但未付款的原因是什么？
- 付款后是否都在 24 小时内确认？
- 孩子是否完成第一个作品？
- 家长最常问的 3 个问题是什么？
- 是否需要调整官网文案、客户端锁定页或订阅中心？

## 5. 转化判断

继续投入的信号：

- 家长能在 1-2 句话内理解知萌是做什么的。
- 下载和安装问题可通过 FAQ 解决。
- 至少 5 个种子用户完成真实付费。
- 至少 3 个孩子完成第一个作品。
- 家长愿意给出可引用反馈或推荐给其他家庭。

暂停或调整的信号：

- 家长普遍不理解“为什么要付费”。
- 下载或安装成为主要流失点。
- 注册到下单转化明显低于预期。
- 孩子打开后不知道做什么，无法开始第一个作品。
- 人工确认流程造成明显不信任或投诉。
