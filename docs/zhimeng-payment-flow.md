# 知萌：购买与支付流程

## 目标

让用户通过下载页完成“下载 - 安装 - 购买 - 登录 - 开通”闭环。

## 推荐路径（MVP）

1. 用户访问下载页
2. 下载 Windows 安装包
3. 应用内点击“订阅解锁”跳转支付页
4. 支付页选择微信/支付宝扫码支付
5. 支付成功后，订单系统回调 entitlement 服务
6. 用户回到客户端重新登录或点击“刷新授权”

## 网页下单 vs 应用内引导

- **网页下单（推荐 MVP）**
  - 优点：实现简单、支付风控成熟、审核材料集中
  - 缺点：跳出应用
- **应用内引导**
  - 优点：体验连贯
  - 缺点：需额外处理内嵌支付风险、回跳和审核

MVP 结论：使用“应用内按钮跳网页支付”模式。

## 支付渠道接入要点

- 微信支付：
  - 需企业主体与商户号
  - 配置支付回调地址与签名校验
- 支付宝：
  - 需企业主体与应用签约
  - 配置异步通知地址

## 订单与 entitlement 关联策略

1. 订单创建时绑定 `user_id`
2. 支付回调成功后，服务端更新 entitlement（状态、到期时间、套餐特性）
3. 客户端在登录或手动刷新时拉取最新 entitlement

## 客户端文案建议

- 未登录：`登录并订阅解锁云保存、分享与社区能力`
- 已登录未订阅：`当前账号未开通订阅，前往购买`
- 已过期：`订阅已到期，续费后恢复完整能力`
