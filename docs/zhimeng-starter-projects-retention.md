# 知萌新用户首个作品与留存设计

## 1. 目标

知萌首发阶段不只验证“能否付款”，还要验证孩子买完后是否能开始创作。

新用户第一次打开完整编辑器时，最容易流失的原因不是功能不足，而是不知道第一步该做什么。因此产品需要把第一次使用收敛成清晰的三个入口：

- 会说话的小角色：3-5 分钟，让孩子理解积木和画面变化的关系。
- 生日祝福动画：5-8 分钟，让孩子用编程做熟悉的表达。
- 接水果小游戏：8-12 分钟，让孩子第一次理解规则和互动。

## 2. 设计原则

- 不把新手引导做成阻塞弹窗；孩子和家长可以随时收起。
- 首屏直接给出“做什么”，不要求用户先理解完整编辑器。
- 每个入口都对应一个可见作品，而不是抽象知识点。
- 运营跟进围绕“是否完成第一个作品”，而不是只问是否安装成功。

## 3. 当前落地

- 官网 `website/index.html` 增加“孩子打开后，先从这 3 个作品开始”，用于购买前建立可交付预期。
- 客户端 `src/components/gui/gui.jsx` 在解锁后展示“从第一个作品开始”轻量入口，点击后打开教程库。
- 运营台 `website/ops.html` 增加已开通提醒、首次创作跟进、反馈收集话术，用于人工确认后的留存跟进。

## 4. 种子用户跟进字段

种子用户表需要持续记录：

- 是否进入完整编辑器。
- 是否点击第一个作品入口。
- 是否完成第一个作品。
- 完成的是故事、动画还是小游戏。
- 孩子是否愿意继续尝试。
- 家长是否愿意推荐给其他家庭。
- 卡住的步骤和截图。

## 5. 后续增强

- 为三个入口补真实项目模板，而不仅是打开教程库。
- 增加“完成第一个作品”后的轻量成就反馈。
- 让家长能看到孩子完成了什么作品和下一步建议。
- 从 3 个 starter projects 扩展到 5-10 个按年龄和主题组织的新手项目。
