# 新祥编程首批内测安装指南

本文只适用于首批内测安装包。当前 macOS 包尚未完成 Apple Developer ID 签名与 notarization，Windows 包也尚未完成正式代码签名，因此系统可能会显示安全拦截提示。

正式公开售卖前，必须替换为已签名、已公证的安装包。请不要把本文作为长期公开分发说明。

## 1. 下载前确认

只从官方或客服提供的链接下载安装包，不要转发来历不明的安装包。

macOS 选择：

- M1 / M2 / M3 / M4：下载 macOS Apple 芯片版。
- 较早 Intel Mac：下载 macOS Intel 芯片版。

Windows 选择：

- 长期使用：下载 Windows 安装版。
- 先体验或不方便安装：下载 Windows 便携版。

## 2. macOS 安装

### 2.1 正常安装

1. 双击打开 `.dmg` 文件。
2. 把“新祥编程”拖到 `Applications` 文件夹。
3. 打开“应用程序”，找到“新祥编程”。
4. 首次打开时，如果系统提示无法验证开发者，先点“取消”。
5. 按住 Control 键点击“新祥编程”，选择“打开”。
6. 在弹窗中再次选择“打开”。

### 2.2 如果提示“已损坏，无法打开”

如果看到“新祥编程已损坏，无法打开。你应该推出磁盘映像”，按下面步骤处理：

1. 确认已经把“新祥编程”拖进 `Applications`。
2. 打开 macOS 的“终端”。
3. 执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/新祥编程.app
   ```

4. 回到“应用程序”，再次打开“新祥编程”。

如果仍然无法打开，请把以下信息发给客服：

- Mac 型号或芯片类型。
- macOS 版本。
- 下载的是 Apple 芯片版还是 Intel 芯片版。
- 报错截图。

## 3. Windows 安装

### 3.1 Windows 安装版

1. 双击 `zhimeng-setup-*.exe`。
2. 如果出现 Windows SmartScreen 提示，点击“更多信息”。
3. 点击“仍要运行”。
4. 按安装向导完成安装。

### 3.2 Windows 便携版

1. 下载 `zhimeng-portable-*.exe`。
2. 如果浏览器或 Windows 提示未知发布者，确认文件来自官方或客服链接后再继续。
3. 双击运行。

## 4. 安装后开通

1. 打开新祥编程客户端。
2. 注册或登录新祥编程账号。
3. 在客户端进入“订阅解锁”。
4. 选择家庭年卡或 7 天项目陪跑包，并扫码付款。
5. 提交付款凭证。
6. 运营确认到账后，回到客户端点击“刷新授权”。

## 5. 给客服的判断口径

- 这是首批内测包，不是最终公开发布包。
- macOS 的“已损坏”提示来自 Gatekeeper 对未签名/未公证包的拦截，不代表用户电脑损坏。
- 只协助从官方链接下载的用户绕过拦截。
- 如果用户不愿意执行绕过步骤，应建议等待已签名、公证后的正式包。
