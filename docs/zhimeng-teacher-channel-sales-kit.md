# 新祥编程老师渠道试销执行包

适用时间：2026-06-28 起第一轮老师渠道小样本试销。

本执行包承接 `docs/zhimeng-teacher-channel-web-battle-map.md`，用于让 3-5 位老师、KOL 或小机构可以直接开始转发联名链接、解释产品、引导家长体验和配合复盘。

## 1. 本轮目标

本轮不是招大规模代理，也不是卖完整机构版。目标是验证：

- 老师是否愿意真实转发。
- 家长是否愿意从老师联名页进入 Web 体验或下载桌面端。
- 老师来源订单能否产生真实付款和正向利润。
- 付款家庭是否能完成第一个作品。
- 老师是否愿意二次推广或升级渠道包。

## 2. 合作对象边界

优先邀请：

- 自由编程老师。
- 少儿编程小机构主理人。
- 亲子社群主。
- 素质教育 KOC / KOL。
- 有少儿编程内容能力的社群运营者。

暂不邀请：

- 在职中小学教师参与返佣。
- 不能解释产品、只想拿佣金的人。
- 要求隐藏新祥编程品牌、隐藏 AGPL 或 Scratch 关系说明的人。
- 要求改产品名、改 App 图标、改支付通道后才愿意试的人。

必须说明：

- 新祥编程不是 Scratch 官方产品。
- 当前不是直播课、长期一对一课或学校课程。
- 付款、授权、客服、退款由新祥编程统一承接。
- 老师联名页只是推荐入口，不改变产品主体和交付责任。

## 3. 老师入口配置

老师配置维护在 `website/data/teacher-channels.json`。新增老师前必须完成：

| 字段 | 填写要求 |
| --- | --- |
| `slug` | 链接参数，建议用英文或拼音，例如 `teacher_a` |
| `enabled` | 是否启用，对外前必须为 `true` |
| `teacher_id` | 内部老师或机构 ID |
| `referrer_code` | 推荐码，必须唯一 |
| `landing_page_id` | 联名页 ID，必须唯一 |
| `display_name` | 对外展示名 |
| `avatar_or_logo_url` | 老师头像或机构 Logo，必须为已审核资源 |
| `intro` | 一句话定位，不承诺课程效果 |
| `recommendation` | 老师推荐语，不得宣称官方、升学、竞赛或固定直播 |
| `source_type` | `kol` 或 `channel` |

当前可试销链接模板：

| 入口 | 示例 |
| --- | --- |
| 老师联名页 | `https://zhimeng.codevalley.cn/teacher.html?teacher=teacher_a` |
| Web 体验入口 | `https://zhimeng.codevalley.cn/app.html?ref=teacher_a&landing_page_id=teacher-a&source_type=kol` |
| 下载入口 | `https://zhimeng.codevalley.cn/index.html?ref=teacher_a&landing_page_id=teacher-a&source_type=kol#download-heading` |

对外优先发老师联名页，不直接发购买页。购买由 Web 体验、桌面客户端或客服辅助链路承接。

## 4. 给老师的一句话

> 这是一个少儿创意编程启蒙工具，不是直播课。你可以发自己的联名体验页给家长，让孩子先低成本做出第一个作品；如果家长付款，我们按确认订单给你结算推荐佣金，并按作品完成和退款风险复盘是否继续合作。

## 5. 老师转发给家长的话术

### 朋友圈 / 社群版

我最近在试用一个少儿创意编程启蒙工具「新祥编程」。

它适合 6-10 岁孩子用积木编程做故事、动画和小游戏。我的建议是：先别急着报很重的课程，先让孩子用一个低成本工具做出第一个作品，再判断要不要继续系统学习。

这里是我的联名体验页：__老师联名页链接__

家长可以先打开 Web 体验，也可以下载桌面客户端。当前有家庭年卡 199 元/年，另有 7 天项目陪跑包 699 元/期，适合希望孩子这一周完成 3 个入门作品的家庭。

说明：新祥编程不是 Scratch 官方产品，也不是直播课或学校课程，付款和开通由新祥编程统一承接。

### 一对一家长版

你可以先打开这个链接：__老师联名页链接__。

我建议先让孩子完成 3 个入门作品中的第一个：会说话的小角色。这个阶段重点不是学复杂知识，而是让孩子看到自己能用积木做出互动作品。

如果孩子愿意继续，可以再考虑家庭年卡或 7 天项目陪跑包。付款和授权由新祥编程处理，我这边主要负责推荐和解释，不承诺固定直播课或长期一对一辅导。

### 现场演示版

今天先看 3 分钟，不讲复杂概念。孩子打开 Web 体验后，只要能让角色说一句话、动一下，就已经完成第一步。

后面再看孩子是否愿意继续做生日祝福动画和接水果小游戏。愿意继续，再考虑年卡或陪跑包。

## 6. 家长 FAQ 速答

| 家长问题 | 老师可回答 |
| --- | --- |
| 这是 Scratch 官方吗？ | 不是。新祥编程基于 Scratch GUI 开源项目改造，遵守 AGPLv3 许可并提供源码。 |
| 是直播课吗？ | 不是直播课。当前主要是创意编程工具和短周期项目陪跑。 |
| 一定要安装吗？ | 可以先打开 Web 体验入口降低门槛，正式创作建议下载桌面端。 |
| 付款后谁开通？ | 新祥编程运营核对到账后开通账号授权。 |
| 老师负责售后吗？ | 账号、付款、授权和退款由新祥编程承接；老师负责推荐、解释和必要的体验引导。 |
| 孩子能做什么？ | 第一轮先做 3 个入门作品：会说话的小角色、生日祝福动画、接水果小游戏。 |

## 7. 三个入门作品说明

| 作品 | 时间 | 老师说明 |
| --- | ---: | --- |
| 会说话的小角色 | 3-5 分钟 | 让孩子理解积木和舞台效果之间的关系。 |
| 生日祝福动画 | 5-8 分钟 | 把编程变成孩子熟悉的表达。 |
| 接水果小游戏 | 8-12 分钟 | 第一次理解规则、控制和互动。 |

老师演示顺序：

1. 先展示联名页。
2. 点击 Web 体验入口。
3. 讲“今天只做第一个小目标”。
4. 让孩子完成会说话的小角色。
5. 家长愿意继续时，再推荐桌面端、年卡或 7 天陪跑包。

## 8. 佣金和结算口径

本轮建议佣金：

| 套餐 | 售价 | 建议佣金 | 备注 |
| --- | ---: | ---: | --- |
| 家庭年卡 | 199 元/年 | 40 元/单，最高不超过 60 元 | 年卡利润薄，不做高佣金 |
| 7 天项目陪跑包 | 699 元/期 | 100 元/单；老师参与轻交付可到 150 元 | 必须控制交付成本 |
| 渠道/机构启动包 | 4999 元/包 | 本轮暂不默认返佣，单独评估 | 进入第 5 阶段后再标准化 |

结算规则：

- 只按已确认付款且未退款的订单计算佣金。
- 退款、重复付款、争议、冻结订单不进入有效佣金，或在结算前扣回。
- 运营台逐单记录 `commission_cents`，渠道复盘模块按推荐码汇总。
- 建议每周结算一次，结算前复核付款、退款风险、首作完成和交付成本。
- 禁止暗返、私下红包或无法入账的佣金。

## 9. 7 天试销节奏

| 天数 | 老师动作 | 运营动作 | 验收 |
| --- | --- | --- | --- |
| D0 | 确认老师链接、话术和佣金规则 | 配置 `teacher-channels.json`，发专属链接 | 老师能打开自己的联名页 |
| D1 | 转发给 5-10 个家庭 | 记录老师候选和触达数 | 至少 3 个家长打开链接 |
| D2 | 现场或私聊演示第一个作品 | 跟进 Web 体验、下载、注册 | 至少 1-2 个家庭注册 |
| D3 | 推动创建订单 | 记录推荐码、套餐和付款状态 | 至少 1 个订单 |
| D4 | 推荐 7 天陪跑包 | 核对付款并开通 | 至少 1 个真实付款或明确流失原因 |
| D5-D6 | 跟进孩子是否完成作品 | 记录首作完成、风险和反馈 | 至少 1 个作品反馈 |
| D7 | 和老师复盘是否继续推 | 看收入、佣金、利润和退款风险 | 决定继续、暂停或调整 |

## 10. 每位老师通过/暂停标准

通过：

- 7 天内触达 5-10 个家庭。
- 至少 2 个家庭认真打开体验或下载。
- 至少 1 个真实付款家庭，或能明确解释为什么暂未付款。
- 付款家庭至少 50% 完成第一个作品。
- 老师愿意继续解释产品，而不是只转发链接。

暂停：

- 老师不愿解释产品，只要求高佣金。
- 家长大量误解为直播课、一对一课或学校课程。
- 推荐订单退款或投诉风险明显高于私域订单。
- 扣除佣金和交付成本后利润为负。

## 11. 运营执行清单

每新增一个老师：

1. 检查合作对象是否符合边界。
2. 在 `website/data/teacher-channels.json` 新增配置。
3. 打开 `teacher.html?teacher=__slug__` 检查展示名、推荐语、Logo 和链接归因。
4. 把联名页链接发给老师。
5. 把本执行包第 5-8 节发给老师。
6. 在 `docs/zhimeng-teacher-channel-pilot-tracker.csv` 记录候选、推荐码和状态。
7. 每天在运营台查看老师来源订单和风险。
8. D7 填写作战图数据复盘模板。
